# VPN для ТВ — per-app AmneziaWG для Tuvio / YaOS

![version](https://img.shields.io/badge/version-1.1.0-blue)
![android](https://img.shields.io/badge/Android-11%20(API%2030)-3DDC84?logo=android&logoColor=white)
![protocol](https://img.shields.io/badge/protocol-AmneziaWG-6f42c1)
![abi](https://img.shields.io/badge/ABI-armeabi--v7a%20%7C%20arm64--v8a-lightgrey)

Android TV-приложение, которое пускает через VPN **только выбранные приложения** (YouTube, браузер…),
а всё остальное на телевизоре работает напрямую. Протокол — официальный
[AmneziaWG](https://github.com/amnezia-vpn/amneziawg-android): backend, парсер и криптография не изменены.

Сделано для телевизора **Tuvio TD43UFBSV1** (YaOS = Android 11), где нет ADB, Google Play
и нормального VPN-клиента с раздельным туннелем. Управление — только пультом.

## Возможности

- **Per-app allowlist** — через туннель идут только отмеченные приложения (`addAllowedApplication`).
- **Импорт с флешки** — `.conf` AmneziaWG/WireGuard и `.vpn` / `vpn://…` из клиента Amnezia.
  Конфиг копируется во внутреннюю память, флешку можно вынуть.
- **Переподключение** — потеря сети, нет handshake, молчащий сервер → повторы с backoff 3…300 с.
- **Автоподключение** при запуске и после загрузки ТВ.
- **Диагностика** — внешний IP через VPN и напрямую, ABI устройства, версия amneziawg-go.
- **Журнал** (1.1.0) — пишется на устройстве и выгружается на флешку кнопкой. Ключей в нём нет.

## Установка за 2 минуты

1. Скопируйте APK и файл конфигурации (`.vpn` / `.conf`) на флешку, вставьте в ТВ.
2. Файловый менеджер ТВ → APK → **Установить** (разрешите неизвестные источники).
3. **КОНФИГУРАЦИЯ → ИМПОРТИРОВАТЬ С USB** → файл конфигурации.
4. **ПРИЛОЖЕНИЯ** → отметить YouTube → **СОХРАНИТЬ**.
5. **ПОДКЛЮЧИТЬ** → OK в системном окне.

Подробно, с запасными путями — [docs/INSTALL.md](docs/INSTALL.md).

## Известные ограничения

- На ТВ нет ADB → установка только с флешки, проверки — на эмуляторе Android 11.
- Точный ABI Tuvio неизвестен → в APK обе ARM-архитектуры.
- Автоподключение после перезагрузки на YaOS не подтверждено (`BOOT_COMPLETED`).
- DoH/DoT внутри приложений VPN не перехватывает (но такой трафик всё равно идёт через туннель).

## Исходный код и лицензия

Приложение — модуль `:tv` в форке [amnezia-vpn/amneziawg-android](https://github.com/amnezia-vpn/amneziawg-android)
(ветка `tv-per-app`, сборка 1.1.0 — коммит `8cd0625`). Код модуля в этот репозиторий пока не выложен.
Upstream распространяется под Apache-2.0, amneziawg-go — под MIT.

> ⚠️ Файлы конфигурации (`.vpn`, `.conf`) содержат приватный ключ — не коммитьте их.
> Ключ подписи release (`release.jks`) храните отдельно: без него обновления не встанут поверх.
