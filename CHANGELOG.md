# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-05

### Добавлено
- Журнал на устройстве: `files/logs/vpn.log` (+ `vpn.log.1`, ротация ~512 КБ). Пишутся запуск,
  подключение/отключение, смены состояния туннеля с текстом ошибки, подъём туннеля (конфиг,
  endpoint, allowlist), потеря/возврат сети, повторы, импорт/удаление конфигов, изменение списка
  приложений, падения со стеком.
- «Диагностика → **Сохранить журнал на флешку**»: системное окно сохранения, файл
  `vpn-log-ГГГГ-ММ-ДД-ЧЧММ.txt` с шапкой (версия, устройство, Android/API, ABI, amneziawg-go,
  состояние, список приложений, автоподключение, последняя ошибка). Без системного окна —
  запись в корень флешки при «Доступе ко всем файлам».

### Безопасность
- Проверено: приватный ключ, PSK и публичный ключ из реального конфига в журнал не попадают (0 совпадений).

## [1.0.0] — 2026-10-05

### Добавлено
- Модуль `:tv` поверх официального `amneziawg-android` (v3.1.4, amneziawg-go v3.1.20260814).
- Экраны: главный (подключить / приложения / конфигурация / диагностика / автоподключение),
  выбор приложений (LAUNCHER/LEANBACK_LAUNCHER, выбранные сверху), несколько конфигураций
  с выбором активной, встроенный выбор файла с USB, диагностика с IP через VPN и напрямую.
  Крупные кнопки, рамка фокуса, управление только пультом.
- Per-app: из конфига вычищаются `IncludedApplications`/`ExcludedApplications`, подставляется
  свой allowlist; пустой список запрещён (иначе full-tunnel).
- Импорт `.conf` и Amnezia `vpn://` (с подстановкой `$PRIMARY_DNS`/`$SECONDARY_DNS`), BOM/CRLF,
  ошибки без значений полей.
- Переподключение: потеря сети → стоп через 8 с и подъём при возврате; нет handshake 45 с →
  backoff 3…300 с; отзыв VPN-разрешения — без повторов. Foreground-сервис, `BOOT_COMPLETED`.

### Исправлено (до релиза, найдено тестами)
- Запоздалый `onDestroy` старого `VpnService` гасил новый туннель при смене списка — теперь
  ожидается фактическое уничтожение сервиса.
- Список конфигураций уходил за экран; нижняя кнопка не помещалась в 540dp.

### Сборка
- `tunnel/tools/libwg-go/Makefile`: Go 1.24.2 → 1.25.0 + `GOTOOLCHAIN=local` (иначе не применялся
  runtime-патч BOOTTIME). Единственная правка официального кода.

### Проверено
- Эмулятор Android 11 (arm64, без GMS) с реальным сервером: per-app разделение по UID, изменения
  на лету, обрыв сети, мёртвый сервер. JVM-тесты 5/5.
- Установлено на Tuvio: YouTube работает через VPN.
