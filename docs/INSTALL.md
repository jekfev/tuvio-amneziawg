# Установка на Tuvio (YaOS, Android 11)

> Обновление с 1.0.0: просто установите новый APK поверх — настройки сохранятся.

## Что положить на флешку

- `VPN-TV.apk` — из [releases/](../releases/);
- файл конфигурации из Amnezia (`.vpn`) или AmneziaWG/WireGuard (`.conf`).

Если записываете с Mac — перед извлечением выполните `dot_clean -m /Volumes/<ФЛЕШКА>`,
иначе файлы `._*` на ТВ выглядят как второй битый APK.

## Шаги

1. Вставьте флешку в телевизор.
2. Откройте файловый менеджер телевизора → флешка → `VPN-TV.apk` → **OK** → **Установить**.
   Если спросит «Неизвестные источники» — разрешите для этого файлового менеджера.
3. Запустите **«VPN для ТВ»**.
4. **КОНФИГУРАЦИЯ → ИМПОРТИРОВАТЬ С USB** → выберите флешку → файл конфигурации.
   Если флешки не видно: **ВСТРОЕННЫЙ ВЫБОР ФАЙЛА → РАЗРЕШИТЬ ДОСТУП К ФАЙЛАМ** → включить →
   Back → флешка → файл.
5. Back → **ПРИЛОЖЕНИЯ** → OK на YouTube (и других нужных) → Back → **СОХРАНИТЬ**.
6. **ПОДКЛЮЧИТЬ** → в окне «Запрос на подключение» нажмите **OK**.
7. **ДИАГНОСТИКА → ПРОВЕРИТЬ ПОДКЛЮЧЕНИЕ** → должно быть «VPN работает».

После импорта флешку можно вынуть. **Файл конфигурации содержит ключ вашего VPN — после
импорта удалите его с флешки.**

## Журнал ошибок

**ДИАГНОСТИКА → СОХРАНИТЬ ЖУРНАЛ НА ФЛЕШКУ** → выберите флешку → **Сохранить**.
На флешке появится `vpn-log-ГГГГ-ММ-ДД-ЧЧММ.txt` — его можно открыть на компьютере.
Ключей VPN в нём нет.
